# tiny-chess-01

A deterministic chess engine that fits in **4096 bytes** — alpha-beta search with
piece-square evaluation, MVV-LVA move ordering and quiescence, written in Python 3.13
by an AI agent (packed entrypoint, source in `main_src.py`).
